# BettermanAI Copilot

> **Your Personal Workflow Optimizer — Automate What You Do, by Just Doing It.**

BettermanAI is a lightweight, local-first AI agent that observes your daily tasks, learns your patterns, asks smart questions, and helps you automate repetitive work. Built for efficiency and designed with privacy in mind.

---

## 🚀 **Project Overview**
BettermanAI watches how you interact with your computer (mouse, keyboard, active window) and intelligently detects workflows that could be automated. It suggests optimizations, asks for your approval, and records macros to run those tasks for you in the future.

The development approach is **batch-based**, with small, focused feature deliveries. This makes it easier to validate each step and ensures a stable, user-friendly product.

---

## 🧩 **System Components**

| Component               | Description                                |
|-------------------------|--------------------------------------------|
| Event Listener          | Tracks mouse, keyboard, and active window  |
| Context Analyzer        | Classifies tasks and sequences            |
| Pattern Detector        | Identifies repetitive behaviors           |
| Reasoning Engine (LLM)  | Generates questions & suggestions (OpenAI API for MVP) |
| Macro Recorder          | Records actions into scripts (PyAutoGUI)  |
| Automation Executor     | Executes recorded macros safely           |
| UX Layer (Frontend)     | User notifications and approvals (Tauri)  |
| Privacy & Settings      | Configure what is tracked and when        |

## 🛡️ **Design Decisions & Justifications**
- **OpenAI API first** (reliable, fast to iterate). Plan to make reasoning engine pluggable for future Ollama or GPT4All fallback.
- **PyAutoGUI as macro engine MVP** (simple, local, cross-platform). Consider upgrade to TagUI if task complexity increases.
- **Tauri chosen over Electron** (minimal RAM footprint, fast startup).
- **Event-driven polling, not constant CPU loops** (to minimize resource use).

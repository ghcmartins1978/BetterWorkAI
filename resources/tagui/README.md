# TagUI Binaries

## Overview
This directory contains the TagUI binaries used by BettermanAI for automation tasks.

## Platform-specific files
In a full implementation, this directory would contain:
- `src/tagui` - TagUI binary for macOS and Linux
- `tagui.exe` - TagUI binary for Windows

## Installation
The binaries should be downloaded from the official TagUI repository and placed in this directory during the build process.

## Documentation
For more information about TagUI, see: https://github.com/kelaberetiv/TagUI

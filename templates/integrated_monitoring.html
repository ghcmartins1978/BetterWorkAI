Rust Helper Installation Guide
About the Rust Helper

The Rust helper application runs on your local machine and allows BettermanAI to interact with your desktop. It enables mouse and keyboard automation, window management, and screen monitoring.

Installation Steps
  1. Download the Rust Helper
    Download the appropriate version for your operating system from our download page.
  2. Run the Application
    Launch the helper application. It should start a local web server on port 17400.
  3. Grant Permissions
    Grant the necessary permissions when prompted (accessibility, screen recording, etc.)
  4. Test Connection
    Return to this page and click "Test & Save Connection" to verify everything is working.
Why do I need this?

BettermanAI is a hybrid application. The web interface runs on Replit's servers, while the automation capabilities require a local application to access your desktop. For privacy and security, automation code runs locally on your computer.

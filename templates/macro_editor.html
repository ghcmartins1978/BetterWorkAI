Working with Macros

Creating a macro is easy:

  1. Click the New Macro button above
  2. Give your macro a name and description
  3. Start recording your actions
  4. Stop recording when you've completed your workflow
  5. Edit or refine your macro steps as needed

You can edit any macro to refine its steps:

  • Click the button next to any macro
  • Modify step parameters like delay times or coordinates
  • Add or remove steps
  • Change conditions or add variables
  • Test your changes with a dry run

BettermanAI offers advanced macro capabilities:

  • Variables: Make macros adaptable by using variables that can be set at runtime
  • Conditional Steps: Create branches in your workflow based on conditions
  • Loops: Repeat actions multiple times with configurable loops
  • Error Handling: Define what should happen if a step fails
  • Scheduling: Set macros to run automatically at specific times

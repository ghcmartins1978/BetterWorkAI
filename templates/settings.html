Variable Handling
About Variables

Variables allow your automations to be more flexible by replacing placeholders with actual values at runtime. Use the format {{variable_name}} in your macros.

If disabled, macros with missing required variables will not be executed
If enabled, the last used value for each variable will be remembered
If enabled, variables in macro steps will be detected and registered automatically
If no input is provided within this time, the macro execution will be aborted
Advanced Variable Features
Advanced Variable Usage

Use \{\{variable:format\}\} for formatted values (e.g., \{\{price:0.2f\}\}) and \{\{if:condition:then:else\}\} for conditional logic.

If enabled, you can format variables using \{\{variable:format\}\} syntax
If enabled, you can use \{\{if:variable:then:else\}\} syntax for conditional logic

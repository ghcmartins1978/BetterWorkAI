Variable System Documentation

The BettermanAI variable system allows you to create dynamic, reusable automation macros by parameterizing values that change between executions.

Basic Syntax

Variables are enclosed in double curly braces:

{{ '{{variable_name}}' }}

When your macro runs, BettermanAI will replace this placeholder with the actual value of the variable.

Example

Scenario: Automating a data entry task

Instead of hard-coding "John Smith" in the macro, use {{ '{{customer_name}}' }} to make the macro reusable with different customer names.

Variable Types

  • string Text values (names, addresses, etc.)
  • number Numeric values (integers, decimals)
  • boolean True/false values
  • choice Selection from predefined options
  • date Date and time values

Specify the correct type for better validation and formatting options.

Advanced Formatting

You can apply formatting to variables using the colon syntax:

{{ '{{variable_name:format}}' }}
Format Example Description
upper {{ '{{name:upper}}' }} Convert text to UPPERCASE
lower {{ '{{name:lower}}' }} Convert text to lowercase
title {{ '{{name:title}}' }} Capitalize First Letter Of Each Word
calc {{ '{{number:calc:*2}}' }} Perform arithmetic operations (*, /, +, -)
dateformat {{ '{{date:dateformat:%Y-%m-%d}}' }} Format date according to strftime patterns

Conditional Expressions

You can use conditional expressions to include different text based on variable values:

{{ '{{if:condition:then_value:else_value}}' }}
Examples

Basic Boolean:

{{ '{{if:is_premium:Premium User:Regular User}}' }}

If is_premium is true, outputs "Premium User", otherwise "Regular User"

Variable Comparison:

{{ '{{if:count>10:Many items:Few items}}' }}

If count is greater than 10, outputs "Many items", otherwise "Few items"

String Comparison:

{{ '{{if:status=completed:✓ Done:⏳ Pending}}' }}

If status equals "completed", outputs "✓ Done", otherwise "⏳ Pending"

Best Practices

Do's
  • Use descriptive variable names
  • Set default values for optional variables
  • Add clear descriptions for each variable
  • Group related variables with similar naming patterns
Don'ts
  • Use spaces in variable names
  • Create too many required variables
  • Nest variables inside other variables
  • Use variables for security-sensitive information

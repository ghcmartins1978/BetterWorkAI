Variable System Documentation

Variables make your automations more flexible by replacing placeholders with actual values at runtime.

Basic Variables

Use basic variables by enclosing the variable name in double curly braces:

{% raw %}{{variable_name}}{% endraw %}

For example, when automating a login form, you might use:

{% raw %}Username: {{username}}
Password: {{password}}{% endraw %}

When the macro runs, you'll be prompted to enter values for these variables.

Formatted Variables

Format variables to control how they appear using the syntax:

{% raw %}{{variable_name:format_specifier}}{% endraw %}
Text Formatting
  • {% raw %}{{name:upper}}{% endraw %} - Convert to uppercase: "john" → "JOHN"
  • {% raw %}{{name:lower}}{% endraw %} - Convert to lowercase: "John" → "john"
  • {% raw %}{{name:title}}{% endraw %} - Capitalize words: "john doe" → "John Doe"
Number Formatting
  • {% raw %}{{price:0.2f}}{% endraw %} - Format with 2 decimal places: 10 → "10.00"
  • {% raw %}{{quantity:pad:3:0}}{% endraw %} - Pad with zeros: 7 → "007"
Calculations
  • {% raw %}{{price:calc:+10}}{% endraw %} - Add to numeric value: 50 → "60"
  • {% raw %}{{price:calc:-5}}{% endraw %} - Subtract from numeric value: 50 → "45"
  • {% raw %}{{price:calc:*1.1}}{% endraw %} - Multiply numeric value: 50 → "55.0"
  • {% raw %}{{price:calc:/2}}{% endraw %} - Divide numeric value: 50 → "25.0"
Date Formatting
  • {% raw %}{{date:date:%Y-%m-%d}}{% endraw %} - Format dates: "2025-04-27"
  • {% raw %}{{date:date:%B %d, %Y}}{% endraw %} - Format dates: "April 27, 2025"

Conditional Variables

Use conditional expressions to show different values based on another variable:

{% raw %}{{if:condition_variable:then_value:else_value}}{% endraw %}

For example:

{% raw %}{{if:is_member:Welcome back, member!:Sign up to become a member}}{% endraw %}

If is_member is true, yes, 1, or y, it will show "Welcome back, member!" Otherwise, it will show "Sign up to become a member".

Examples
  • Toggle visibility: {% raw %}{{if:show_details:Details: {{details}}:}}{% endraw %}
  • Different messages based on status: {% raw %}{{if:is_approved:Approved:Pending approval}}{% endraw %}
  • Dynamic CSS classes: {% raw %}class="btn {{if:is_primary:btn-primary:btn-secondary}}"{% endraw %}

Variable Management

Variables are automatically detected in your macros, or you can define them manually:

  1. Go to the macro editor
  2. Click on the "Variables" tab
  3. Add or edit variables with descriptions, default values, and types

Variable settings can be configured in the Settings page under the "Automation" tab.

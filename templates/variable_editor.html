Variable Types
  • string

    Text values like names, addresses, etc.

    Example: "John Smith", "Main Street"
  • number

    Numeric values for calculations.

    Example: 42, 3.14, -10
  • boolean

    True/false values for conditions.

    Example: true, false, yes, no
  • choice

    Selection from predefined options.

    Example: "red,green,blue"
  • date

    Date and time values.

    Example: "2025-04-28"
Tips
  • Variables are stored in {{ '{{variable_name}}' }} format in your macro steps.
  • Set default values to make execution easier.
  • You'll be prompted for required variables during execution.
  • Check the documentation for advanced formatting options.

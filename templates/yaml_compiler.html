YAML DSL Documentation

The YAML DSL (Domain Specific Language) provides a more readable way to define automation workflows. The structure consists of three main sections:

1. Metadata

Contains information about the automation workflow:

metadata:
  name: Example Workflow
  description: An example workflow
  id: workflow_001
  tags:
    - example
    - test
2. Variables

Define variables that can be used throughout the workflow:

variables:
  app_name: Notepad
  text_to_type: Hello from BettermanAI!
  wait_time: 1
3. Steps

Define the sequence of actions to perform:

steps:
  - action: echo
    message: Starting workflow
    
  - action: focus
    window: ${app_name}
    
  - action: wait
    seconds: ${wait_time}
    
  - action: type
    target: page
    value: ${text_to_type}
Supported Actions
Action Parameters Description
click target, button Click on a target element or coordinates
hover target Move mouse to a target element or coordinates
type target, value Type text into a target element
keyboard keys Press keyboard keys
wait seconds Wait for a specified number of seconds
focus window Focus on a specific window
echo message Display a message
assign variable, value Assign a value to a variable
url address Navigate to a URL
if condition Start a conditional block
else - Start the else part of a conditional block
for variable, from, to Start a for loop
